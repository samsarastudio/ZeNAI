# Photo frames

PNG/JPG overlays for the keepsake step. Guest photos fill the darkest rectangular hole (photoScale `1` = no inset border).

## Size for gallery + print (no gap)

Export landscape **3:2 (6×4 in)** so the framed photo fills the Moments gallery, live wall, and SELPHY postcard without letterboxing.

| | |
| --- | --- |
| Aspect | **3:2** (width ÷ height = **1.5**) |
| Suggested pixels | **1800×1200** or **2400×1600** |
| Seed example | `botanical-landscape.png` is 1536×1024 (3:2) |

A **16:9** overlay (e.g. 1672×941) is wider than the gallery tile. The extra height of a 3:4 or 3:2 slot shows as empty space at the top (and the white banner of a 16:9 event frame sits in that gap).

Print paper is 148×100 mm (~1.48:1) — 3:2 is the design size; the booth contain-fits it on the postcard.

Included:
- `botanical-landscape.png` — subtle landscape botanical matte (no caption bar; default)
- `botanical-blush.png` — soft botanical white/blush frame
- `onam-grma-2026.png` — GRMA Onam 2026 event frame
- `onam-floral.png` — Onam floral alternate

Add more files here; they appear automatically on the frame picker screen.
Enable/disable per frame and set the default in PhotoBooth Admin → Frames.
Moments Admin → Frames holds the same overlays for Sync / publish.
